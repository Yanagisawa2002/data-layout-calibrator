# Data Layout Calibrator v0.3.0-preview.1

The first public preview packages the workload-agnostic calibration core, two
independent workload plugins, conservative statistical selection, AOT-safe
scenario discovery, and immutable-result visualization as one reviewable Unity
performance-engineering project.

## Highlights

- Reusable `Scenario`, `Candidate`, `Parity`, and `BoundaryCost` plugin
  contracts; the core assembly contains no Particle types.
- Concrete AoS, SoA, and AoSoA8 candidates with tuned batch sizes.
- Full ingress, resident execution, export, and declared-lifetime accounting.
- Typed parity, state hashes, zero-managed-allocation gates, a minimum product
  threshold, non-parametric bootstrap confidence intervals, and untouched
  holdout confirmation.
- Statistical ties and inconclusive results retain the tuned AoS baseline.
- AOT-safe Roslyn Source Generator using direct constructor calls rather than
  reflection or `Activator`.
- A fixed-result heatmap/GIF renderer whose tests prove that presentation cannot
  replace the candidate stored in `FinalDecision`.

## Preregistered formal evidence

Five fresh Windows IL2CPP Release/Burst AOT Player processes used 1,048,576
calibration records, 1,000,003 untouched holdout records, 40 resident samples,
20 boundary samples, 600 lifetime ticks, and 4,000 bootstrap iterations.

- The preregistered primary run selected `SoA-b128` against tuned `AoS-b64` and
  recorded 70.70% lower holdout amortized P95, with a 95% bootstrap CI of
  [65.32%, 79.37%]. The reciprocal-latency throughput equivalent is 3.41x; a
  separate throughput benchmark was not performed.
- Across all five retained launches, ParticleIntegrate recorded 66.11%–74.81%
  lower holdout P95, with a 68.71% median. The worst per-run confidence lower
  bound was 40.07%.
- TransformExport retained tuned AoS in 5/5 launches.
- All retained results passed typed parity and recorded 0 managed allocation in
  resident, ingress, and export measurements.

Every suite is retained under
[`Docs/evidence/formal-il2cpp-2026-09-02`](../evidence/formal-il2cpp-2026-09-02/README.md),
with SHA-256 hashes and exact frozen decisions. These are same-device process
replications on the recorded AMD Ryzen 9 9950X/Windows environment, not a
cross-device or universal performance guarantee.
